# 05 — FUNDING SOURCE RULE

> **EVERY PROPOSED PORTFOLIO ACTION MUST NAME THE SOURCE OF CAPITAL**

---

## The Rule

No proposed Portfolio Action is complete without a named funding source. An
unnamed source means the capital question has not actually been specified,
and the comparison is hypothetical.

## Allowed Categories

- **NEW EXTERNAL CAPITAL**
- **EXISTING TREASURY / CASH SLEEVE**
- **PROCEEDS FROM REDUCING A HOLDING**
- **PROCEEDS FROM EXITING A HOLDING**

Exactly one is named per proposed action. If a proposal genuinely spans two
sources, it is two proposals.

---

## The Existing Book Is a Source of Capital

Do not assume all capital is new money.

**A candidate does not merely compete with cash; it may also compete with
an existing holding for the same dollar.** A holding that is no longer the
best use of the capital tied up in it is itself a funding source. Treating
every capital question as "new money vs. cash" hides that comparison and
biases the book toward whatever it already owns.

Reducing or exiting a holding to fund a better opportunity is a legitimate,
first-class outcome — and, like every outcome here, requires its own
written reasoning.

---

## Separation of Concerns

> **Security Decision ≠ funding decision ≠ Portfolio Action.**

Three distinct things:

- A **Security Decision** is a conclusion about a security in isolation.
- A **funding decision** identifies which capital is at stake and where it
  comes from.
- A **Portfolio Action** moves capital, and is authorized only by the human
  at Stage 8 (`../../manual_pilot_v0_1/04_HUMAN_OPERATING_LOOP.md`).

Concluding a security is attractive says nothing about which dollar would
buy it, and neither one authorizes a trade.

---

## Frictions

**No tax engine.**

If a material real-world friction is supplied by the human operator, record
it **qualitatively only** — as a named constraint on a specific comparison,
in plain language. Frictions are not modeled, computed, optimized around,
or turned into a workstream.

---

## Template

```
FUNDING SOURCE

Date:                  [YYYY-MM-DD]
Recorded by:           [human name / identifier]
Capital question:      [what capital, for what]

Funding source:        [exactly one of:
                        NEW EXTERNAL CAPITAL
                        EXISTING TREASURY / CASH SLEEVE
                        PROCEEDS FROM REDUCING A HOLDING
                        PROCEEDS FROM EXITING A HOLDING]

If proceeds from reducing/exiting:
  Holding being reduced or exited:
  Why that capital is better used elsewhere:

Material frictions noted (qualitative only, if supplied):
  [plain language, or "none supplied"]
```
