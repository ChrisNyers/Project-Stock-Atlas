## Health / Learning

**Classification: PROCEED**

Demonstrated in this controlled paper case:

> ### SOURCE-BLIND CAPITAL ALLOCATION

More precise statement: **source provenance remained logged, while arrival
path did not determine the Stage 8 funding result.**

Also learned:

- Source advantage can be replaced by **idea-interest, familiarity or
  recency advantage** if only provenance is policed.
- **Overlap raises the funding bar** rather than creating comfort.
- **PARK / REVISIT requires a concrete trigger.**
- **Security Decision ≠ Funding Decision ≠ Portfolio Action.**

### Important Limitation

Pilot 3 does **not** prove that source / familiarity bias is eliminated
generally.

It does **not** prove that CBOE will outperform CARR, FICO, SPY or
Treasury.

**It is a controlled process / decision demonstration only.**
