## Discovery purpose — what Pilot 3 is testing

> Can an opportunity-discovery layer surface worthwhile ideas Atlas likely
> would otherwise have missed, and do those ideas survive the existing Atlas
> underwriting process?

**This is not a test of idea volume.** No agent score, source score,
ranking, or discovery-quality algorithm is created here or planned. Agent
World's only recorded properties are: what it surfaced, and what happened to
each surfaced name under Atlas's existing, unchanged process.

### Governing principle

> **Preserve provenance. Remove privilege.**

Agent World's source state (`WATCH`, `CALENDAR`, `MAP_ONLY`) is preserved
below as provenance — a record of where and how each idea arrived. It is
**not** treated as underwriting privilege: no candidate is advanced,
promoted, or funded because of where it came from, and no candidate is
penalized for that reason either. Treatment is driven by the same evidence,
typed uncertainty, alternatives and portfolio-fit standard as every other
Stock Atlas candidate, from Pilot 1 forward.
