# STOCK ATLAS — CORE CAPITAL-ALLOCATION DOCTRINE

*Record ID: SA-DOCTRINE-001 · Recorded 2026-09-02 · Paper / fictional pilots only*

---

## Purpose

Find the best alpha and beta opportunities from multiple legitimate inputs,
underwrite them rigorously, compare them against cash, beta, the existing
portfolio and each other, and put capital in better places only when the
evidence earns it.

---

## Definition of BEST

**Best does NOT mean:**

- highest quality
- cheapest
- newest
- most interesting
- most familiar
- already owned

**Best means:**

> The best place for the next dollar after evidence, typed uncertainty,
> realistic alternatives, portfolio fit, portfolio role and opportunity
> cost are considered.

---

## Core Rules

- **Refuse is legal.**
- **Discovery allocates attention, not capital.**
- **SURFACED ≠ UNDERWRITTEN ≠ ELIGIBLE ≠ FUNDED.**
  *Operational vocabulary evolved through later pilots. The frozen Manual
  MVSA v0.1 state contract remains historical point-in-time methodology;
  this doctrine reflects the current operating vocabulary and does not
  retroactively rewrite v0.1.*
- **CAP ≠ BLOCK.**
- **Security Decision ≠ Funding Decision ≠ Portfolio Action.**
- **Provenance stays. Source / familiarity / sponsorship advantage is
  zero.**
- **Overlap raises the bar; it is not a safety premium.**
- **Hold is an active allocation decision for the unit under review.**
- **Cash initiation ≠ incumbent substitution.**
- **KEEP ≠ DO NOTHING.**
- **Treasury / Cash is productive waiting capital, not a fixed hurdle.**
- **SPY / beta is a deliberate alternative.**
- **Priced-in = Observable Regime → Atlas Variant → Evidence →
  Falsification.**
- **Park / Revisit requires a concrete trigger.**
- **Stage 7 writes. Stage 8 spends.**

---

## Development Rule

> **"If the next page does not change what happens to a unit of capital, it
> is probably bloat."**

Red Team should be used when it can materially change or challenge a
capital judgment, or expose a real governance leak.

**Do not create a new pilot merely because another cognitive bias can be
named.** A new pilot must test a **materially unresolved capital-allocation
question**.

---

## Sequence

> **Method → Decision → Learning → Automation.**

**Automation remains downstream.**
